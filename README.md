# Deal Pursuit Framework

Interactive complexity model for enterprise sales pursuits.

Select deal size ranges to see how requirements, stakeholders, process rigor, artifacts, and SOPs scale from mid-market deals up to full $1B+ strategic pursuits.

## Live Site

To make the site live:

1. Go to the repository Settings → Pages
2. Under Source, select **Deploy from a branch**
3. Choose branch **main** and folder **/ (root)**
4. Save

Once deployed (usually within 1-2 minutes), the site will be available at:

**https://grazedintexas.github.io/deal-pursuit-framework/**

## Features

- Progressive deal size tiers ($50K → $1B+)
- Detailed SOPs and advancement requirements for the full 7-phase $1B model
- Expandable stage cards
- Buying committee, artifacts, and risk guidance

## Usage

Open `index.html` locally in a browser, or visit the GitHub Pages URL once enabled.
